# Surface Brief: Peer Node File Manager

## Scope & Visitor Mode
Scope: `backend/src/main/resources/static/index.html`
Mode: Operate

## Direction contract

THESIS: A distraction-free, high-density P2P file manager that replaces bloated generic admin templates with a crisp, tactile node control center featuring live chunk-state ribbons, distributed mesh search, and peer topology drawers.

OWN-WORLD: Clean monochrome canvas (#0B0F17 in dark / #F8FAFC in light), electric teal/emerald chunk success accents (#10B981), amber retrying status (#F59E0B), indigo network indicators (#6366F1), hairline borders, monospaced metadata chips, and fluid split-flap style chunk bars.

STORY: The operator immediately sees node health and connection info at top, drops or specifies files to chunk and seed, searches the distributed mesh with dynamic TTL hops, and witnesses real-time chunk assembly block by block with retry resilience.

FIRST VIEWPORT: Top app bar with node status badge, peer count, storage metrics, and light/dark toggle. Left main stage features a drag-and-drop file sharing hero card with 1MB chunker above the searchable Shared Files & Network Downloads table. Right docked drawer displays Known Peers with live ping and peer registration form. Bottom drawer exposes diagnostic testing (TCP ping & chunk recovery simulator).

FORM: Clean Minimalist File Manager with split-flap micro-chunk indicators, candidate 4 of grounded list, seed key fca95c4a.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
